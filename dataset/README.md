# Dataset

This folder contains the processed dataset used by the project.

## Included

- `yoga_video_keypoints.csv`
  - MediaPipe Pose landmark dataset extracted from the original yoga videos.
  - Used for feature extraction and model training.

## Raw Video Dataset

The original yoga videos used to generate the dataset are available on Google Drive.

**Google Drive:**

https://drive.google.com/drive/folders/1tCioHTCCwzpAbWRgOlNwV3wWKweACANL?usp=sharing

These videos were processed using MediaPipe Pose to generate the landmark dataset (`yoga_video_keypoints.csv`).
