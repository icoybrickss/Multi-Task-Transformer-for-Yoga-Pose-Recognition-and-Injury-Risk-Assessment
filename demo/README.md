# Prototype Demonstration

This folder contains the demonstration resources for the project:

**Multi-Task Transformer for Yoga Pose Recognition and Injury Risk Assessment**

## Demonstration Video

The complete prototype demonstration is available on Google Drive.

**Google Drive:**

https://drive.google.com/drive/folders/1f4P8qdjWSF5PhFhHAX_L7mzZPp4e453W?usp=sharing

## Demonstration Contents

The video demonstrates the complete workflow of the proposed YogaSafe system, including:

- Uploading a yoga posture video
- Automatic human pose landmark extraction using MediaPipe Pose
- Yoga pose classification using the Multi-Task Transformer model
- Injury risk assessment (Safe / Unsafe)
- Joint-level risk localization
- Integrated Gradients-based model explanation
- Unsafe signal decomposition
- Display of confidence scores and inference results
- Web-based frontend demonstration
- FastAPI backend inference service
